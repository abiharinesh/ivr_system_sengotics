PRIMARY TRIGGER: Any mention of light, illumination, electric post, bulb, or darkness.

TAMIL SCRIPT KEYWORDS:
- தெரு விளக்கு, விளக்கு, ஸ்ட்ரீட் லைட், லைட், வெளிச்சம், இருட்டு, இருட்டா இருக்கு
- எரியல, எரியவில்லை, போடல, போட மாட்டேங்குறாங்க, ஆஃப் ஆயிருக்கு, வேலை செய்யல
- மின்னுது, விட்டு விட்டு எரியுது, ப்ளிங்க் ஆகுது, மங்கலா எரியுது, டிம்மா இருக்கு
- பல்பு, டியூப் லைட், எல்.இ.டி லைட், சோடியம் லைட், ஹை மாஸ்ட் லைட்
- கம்பம், மின் கம்பம், போஸ்ட், லேம்ப் போஸ்ட், போல், தூண், சாஞ்சுடுச்சு, உடைஞ்சு போச்சு
- போல் நம்பர், போஸ்ட் நம்பர், கீபேட் நம்பர், லைட் நம்பர், கம்ப எண்
- சுவிட்ச் பாக்ஸ், டைமர், எம்.சி.பி, பேஸ் கட், கரண்ட் இல்ல (தெருவில் மட்டும்)

SPOKEN TANGLISH / PHONETIC KEYWORDS:
- "street light eriyala" / "light poda maatengranga" / "light off-aa irukku"
- "veetu munnadi light eriyala" / "theru full-aa iruttaa irukku"
- "light blinking" / "light flickering" / "bulb poiduchu" / "tube light cut"
- "lamp post broken" / "post saanjirukku" / "pole crash aayiduchu"
- "pole number KM-01" / "post number 201" / "keypad ID"
- "timer switch work aagala" / "kaalaila kooda light erinjitte irukku" (Day burning)

NEGATIVE DISAMBIGUATION RULE:
- If caller says "லைட்" (light) or "விளக்கு" (lamp) or "எரியல" (not burning),
  it is 100% `street_light`. NEVER classify as `water` or `garbage`!
