Module 1

Advanced GIS & Asset Mapping

Map, visualise, and manage every physical asset across entire districts on an interactive Web Map powered by PostGIS.

At the heart of Sengotics is a PostgreSQL/PostGIS spatial database that stores the precise geographic coordinates and metadata of every physical asset under the municipality's jurisdiction. Officers can view, search, filter, and manage infrastructure directly on a rich, interactive map interface.

🗺️
[ Map Screenshot — Interactive Web Map showing geo-tagged assets across a district ]

⚡ Electrical Poles

Geo-tagged with unique Keypad IDs, wattage, pole type, installation date, and maintenance history. Each pole is a clickable map marker.

💧 Water Pipelines

Imported via GeoJSON pathways — visualise pipeline routes, junction nodes, valve positions, and connection points across the network.

🏛️ Municipal Buildings

Plot government offices, community halls, schools, and health centres as polygon boundaries with area, usage, and condition data.

🔍 Spatial Queries

Find all assets within a radius, along a road, or inside a ward boundary. PostGIS-powered queries return results in milliseconds.

Multi-Layer Map View

Toggle between satellite imagery, street maps, and custom overlay layers. Filter assets by type, status, ward, or date range. Export map views as high-resolution images for reports.

Module 3

E-Tendering & Procurement Engine

Manage the complete tender lifecycle — from draft creation to comparative award — with full audit compliance.

The procurement module digitises every step of the government tendering process. Officers create tenders linked to specific GIS-mapped assets, define line items, set milestone rules, invite vendors, collect quotations, generate comparative statements, and issue work orders — all within a single, auditable workflow.

Tender Lifecycle Stages

  • Draft — Create tender with description, line items, and timeline rules
  • Published — Send invite links to selected vendors
  • Quotation Collection — Vendors submit sealed bids within the deadline
  • Comparative Statement — Auto-generated L1/L2 comparison
  • Award & Work Order — Issue digitally signed work orders
  • Execution & Completion — Track progress against physical assets

Key Capabilities

  • Custom milestone rules (anchor date + offset days)
  • Project line items linked to specific GIS-mapped poles/assets
  • Automated PDF generation for all tender documents
  • Canvas-based document template designer (Fabric.js)
  • Immutable state-transition audit log
  • GeM-compliant procurement workflow

Module 4

Secure Vendor Management & Compliance

A tamper-proof vendor ecosystem with invite-only bidding, automated document generation, and immutable audit trails.

Government procurement demands absolute transparency and traceability. The Sengotics vendor module ensures that only authorised vendors can participate in tenders, every document is generated with consistent formatting, and every action is logged in an immutable, timestamped audit trail.

🔐 Invite-Only Quotation Access

Tenders can be set to "Invited Only" mode — only vendors explicitly invited by the officer can view or submit quotations. Prevents unauthorised bidding and bid manipulation.

📄 Automated PDF Documents

Work orders, comparative statements, and tender notices are generated as professional PDFs using customisable templates with the panchayat's branding and seal.

📊 Vendor Master Database

Centralised registry of approved vendors with GST details, past performance ratings, contact information, and category-wise qualification status.

🔏 Immutable Audit Logs

Every tender state transition (Draft → Published → Awarded) is logged with timestamp, user ID, IP address, and action details. Cannot be edited or deleted.

Government Compliance Built-In

The platform is designed to comply with General Financial Rules (GFR) 2017, GeM procurement guidelines, and state-level public works department (PWD) norms. Every procurement action is auditable and traceable from creation to completion.

Module 6

Field Verification & AI-OCR Inspection

Secure, token-gated inspection sessions with AI-powered image verification to prevent fraudulent work claims.

After a work order is issued and physical work is completed, the system requires on-ground verification before payment release. Field staff use a secure, token-gated mobile interface to upload geo-tagged photographs of completed work — which are then validated by AI-powered OCR.

🔑 Token-Gated Sessions

Each inspection session is secured with a unique, time-limited token. Only authorised field staff can access the upload interface for a specific asset.

📸 Geo-Tagged Photo Uploads

Photos are automatically embedded with GPS coordinates, timestamp, and device metadata. Prevents submission of pre-taken or stock images.

🤖 AI-OCR Validation

The system reads text (pole IDs, serial numbers) from uploaded images using Google Vision AI and calculates a confidence score to verify authenticity.

📊 Confidence Scoring

Each verification attempt receives a confidence percentage. Low scores are flagged for manual review by the supervising officer before approval.

Anti-Fraud by Design

The combination of token-gated access, GPS enforcement, timestamp validation, and AI-OCR cross-referencing creates a multi-layered fraud prevention system that ensures only genuine, verified work is approved for payment.

Module 7

Multi-Tier Administration & Geo-Fenced Resolution

Advanced Role-Based Access Control (RBAC) with geo-fenced operations ensuring accountability at every level.

Sengotics implements a hierarchical, role-based access control system with distinct, secure login portals for each administrative tier. Each role sees only the data and actions relevant to their jurisdiction and responsibility level.

Role Hierarchy

  • Super Admin — Platform-wide configuration, user management, cross-panchayat analytics, and system settings
  • Panchayat Admin (Officer) — Create tenders, manage assets, review field verifications, and generate reports for their jurisdiction
  • Field Staff (Electricians / Plumbers) — View assigned complaints, navigate to asset locations, and submit geo-tagged completion evidence
  • Vendors — View invited tenders, submit quotations, and track work order status via secure portal

Geo-Fenced Operations

  • Field workers must submit completion images from the exact GPS coordinates of the assigned physical asset
  • Configurable geo-fence radius (e.g., 50m, 100m) to account for GPS accuracy
  • Automatic rejection of submissions from outside the geo-fence boundary
  • GPS coordinates logged and displayed on the admin dashboard for every submission
